# 默克尔树 (Merkle Tree) 区块链实验

基于 Python 实现的默克尔树 (Merkle Tree) 构建与 SPV (简单支付验证) 默克尔证明 (Merkle Proof) 实验程序。

默克尔树是区块链（如比特币、以太坊）核心的数据结构之一，用于高效、安全地汇总和校验区块中的大量交易数据。

---

## 核心原理与机制

### 1. Merkle Tree 构建过程

1. **叶子节点计算**：将区块中的每一笔原始交易数据通过 SHA256 计算哈希，作为最底层的叶子节点。
2. **两两哈希向上汇总**：
   - 将相邻的两个节点哈希拼接（`Hash(Node_A + Node_B)`），计算得到父节点哈希。
   - 如果当前层的节点数量为奇数，将最后一个节点自我复制一份补齐为偶数后进行计算。
3. **生成 Merkle Root**：重复上述过程直到最终收敛生成唯一的根节点（Merkle Root），该 Root 被写入区块头 (Block Header) 中。

### 2. 默克尔证明与轻节点 (SPV) 验证

轻节点（SPV 客户端）不需要下载完整的区块链或整个区块的所有交易数据，只需保存区块头中的 Merkle Root。

当验证某笔交易是否包含在区块中时：
- 全节点向轻节点提供该交易的 **Merkle Proof（审计路径 / Audit Path）**。
- 轻节点根据交易数据和 Proof 中的兄弟节点哈希，依次向上计算 Hash。
- 如果最终算出的 Hash 与区块头中的 Merkle Root **完全一致**，即证明交易真实存在且未经篡改。
- 时间与空间复杂度仅为 **O(log N)**，性能极其高效。

## 结果解读与结论

1. **奇数补齐机制验证**：实验中有 5 笔交易（奇数），层级 0 在第 4 节点 `tx5` 后成功自我复制补充了第 5 节点（节点 [4] 与节点 [5] 哈希一致），证明了二叉树向上构造的稳定性。
2. **高效证明 (Merkle Proof)**：针对 5 笔交易中的 `tx3`，仅需 3 个兄弟节点的哈希路径即可在没有任何完整数据的情况下完成验证，验证结果为 `True`。
3. **雪崩效应与防篡改拦截**：将交易中的金钱金额由 `2 BTC` 修改为 `200 BTC` 尝试伪造交易时，密码学哈希函数的雪崩效应导致生成的 Root 完全无法与原 Root 匹配，验证结果为 `False`，成功被拦截。
